# Information Systems Junior Core

This repository organizes coursework and projects from my four junior-core courses.

## Courses

- [IS 401](./is-401) — Projects and coursework for IS 401
- [IS 402](./is-402) — Projects and coursework for IS 402
- [IS 403](./is-403) — Projects and coursework for IS 403
- [IS 404](./is-404) — Projects and coursework for IS 404

## Organization

Smaller assignments live inside their course folder. Larger portfolio projects may use their own repository and will be linked from the appropriate course README.

## Project Documentation Standard

Each project should explain:

- The problem or assignment
- My role and contributions
- Tools and technologies used
- How to run or view the project
- Key lessons learned
